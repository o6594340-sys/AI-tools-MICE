# MICE Draft

AI-инструменты для MICE-менеджера. Одностраничное веб-приложение с 6 режимами: от анализа брифа до генерации концепции программы.

---

## Что умеет

| Режим | Задача |
|---|---|
| Анализ брифа | Резюме запроса + уточняющие вопросы + черновик ответного письма. Определяет сферу компании по названию и не задаёт лишних вопросов |
| Ответ на возражение | Профессиональный ответ без давления (дорого / подумаем / нашли дешевле / не тот формат / долго) |
| Письмо поставщику | Запрос скидки, hold, подтверждение — сразу на русском и английском |
| Редактор текста DMC | Превращает сухой текст DMC в живое описание для КП. Кнопки переработки стиля: Продающе / Подробнее / Ярче / Дерзче / Интеллигентно |
| Follow-up клиенту | Вежливое тёплое письмо клиенту, который молчит после предложения |
| Генератор концепции | Название, идея и логика программы для усиления КП |

**Ключевое отличие от ChatGPT:** не придумывает факты, адаптирует под MICE-контекст, знает терминологию и форматы индустрии.

---

## Загрузка файлов

В режимах **Анализ брифа** и **Редактор DMC** можно прикрепить файл — система извлечёт текст автоматически.

| Формат | Анализ брифа | Редактор DMC |
|---|---|---|
| PDF (.pdf) | ✓ | ✓ |
| Word (.docx) | ✓ | ✓ |
| Excel (.xlsx) | ✓ | — |
| PowerPoint (.pptx) | — | ✓ |

## Стек

- Python / Flask
- Anthropic Claude API (потоковая передача)
- Vanilla JS + marked.js
- HTML / CSS (без фреймворков)
- pypdf, python-docx, openpyxl, python-pptx — извлечение текста из файлов

## Запуск

**Windows (быстрый старт):**
```
start.bat
```

**Вручную:**
```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. Создать .env
cp .env.example .env
# вписать ANTHROPIC_API_KEY=sk-ant-...

# 3. Запустить
python app.py
```

Открыть: [http://localhost:8080](http://localhost:8080)
