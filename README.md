# MICE Draft

AI-инструменты для MICE-менеджера. Одностраничное веб-приложение с 6 режимами: от анализа брифа до генерации концепции программы.

---

## Что умеет

| Режим | Задача |
|---|---|
| Анализ брифа | Резюме запроса + уточняющие вопросы + черновик ответного письма |
| Ответ на возражение | Профессиональный ответ без давления (дорого / подумаем / нашли дешевле / не тот формат / долго) |
| Письмо поставщику | Запрос скидки, hold, подтверждение — сразу на русском и английском |
| Редактор текста DMC | Превращает сухой текст DMC в живое продающее описание для КП |
| Follow-up клиенту | Короткое письмо клиенту, который молчит после предложения |
| Генератор концепции | Название, идея и логика программы для усиления КП |

**Ключевое отличие от ChatGPT:** не придумывает факты, адаптирует под MICE-контекст, знает терминологию и форматы индустрии.

---

## Стек

- Python / Flask
- Anthropic Claude API (потоковая передача)
- Vanilla JS + marked.js
- HTML / CSS (без фреймворков)

---

## Запуск

```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. Создать .env
cp .env.example .env
# вписать ANTHROPIC_API_KEY=sk-ant-...

# 3. Запустить
python app.py
```

Открыть: [http://localhost:5000](http://localhost:5000)
